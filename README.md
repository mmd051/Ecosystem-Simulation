# Ecosystem-Simulation
Ecological Ecosystem Simulation
A Python-based, object-oriented simulation that models dynamic interactions between various animal and plant species within a shared environment over a configurable timeframe.

Key Features
Dynamic Entities & Attributes: Implemented distinct classes for plants and animals, tracking real-time metrics such as health, energy/power, growth rates, and reproductive states.

Environmental Influences: Entities dynamically react to changing variables including weather conditions, seasonal shifts, and resource availability.

Survival & Crisis Mechanics: Integrated logic for predator-prey behavior, metabolic consumption, and adaptive survival mechanisms during random environmental catastrophes.

Object-Oriented Design: Developed using clean OOP principles (Inheritance, Polymorphism, and Encapsulation) to maintain scalable and modular agent behaviors.
